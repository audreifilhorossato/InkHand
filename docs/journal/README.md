# Lab journal

The source of truth is a handwritten lab notebook (numbered pages, in Portuguese).
Each session is transcribed here in English, one file per session: `YYYY-MM-DD.md`.
Days with no notebook pages can share one entry, named after the first and last day: `YYYY-MM-DD_to_YYYY-MM-DD.md`.

Template:

```
# YYYY-MM-DD · Session N · Topic
Goal / Done / Measurements / Problems → fixes / Decisions and why / Pending / Photos / Next step
```

Photos are numbered in order across sessions (`docs/photos/F001.jpg`, `F002.jpg`, …) and listed in the session's entry.
Scans of the notebook pages are kept out of the public repo because they show my handwriting.
